## F5 固定 40% 的诊断更正

2026-09-10 在当前本地页面复现：

| 观察项 | 实际结果 |
|---|---|
| 地址 | `http://127.0.0.1:8765/` |
| 页面选择 | F5 |
| 拖动目标 | 第 75 帧，界面显示 3.00 秒 |
| `video.currentTime` | **0 秒** |
| `video.seekable` | **[0, 0]** |
| 视频完整缓冲范围 | [0, 4.04] 秒 |
| 网页液位 | 40.0% |
| `Range: bytes=1000-1999` 响应 | HTTP 200，完整 3,880,292 字节；没有 `Content-Range` / `Accept-Ranges` |

当前本地 Python 简易服务器不支持该视频所需的分段请求。网页按目标帧更新时间和真值，但视频跳转被限制在第 0 帧，随后一直分析初始画面。上一轮把浏览器的固定读数归因于时序跟踪停滞，判断不准确。离线 Python 对完整 MP4 的检测误差属于另一个问题，不能据此解释视频本身不动。

实际修复：将小体积外部视频完整加载为浏览器 Blob，再执行精确跳转。这样同一个网页兼容没有 Range 支持的静态服务器，同时加入跳转结果检查和快速切换时的取消处理；网页结构和检测算法保持原样。

本地及 GitHub Pages 均通过 `tests/video_playback.browser.js`：F4/F5 的初帧、中间帧、末帧有不同的解码像素，媒体时间分别为约 0.02、2.02、4.02 秒；播放、重播、拖动、快速切换及原 F1 案例正常。没有用真值替换检测输出。原 F5 在高液位的离线检测误差仍然存在，它与冻结问题分开记录。

## 实拍对照与材质调整

参考 `RealCapture/15% Pump 1` 中第 525 张和 `60% Pump 2` 中第 30 张有效 TIFF，对照其无损查看图 `outputs/digital_twin/15_525.png`、`60_30.png`。主要外观依据是：下半部更密集的附着物、斑块间透明空隙、断续水线、干燥流痕，以及玻璃顶部和弧形底部的不均匀浑浊。

根据用户进一步要求，本稿明显加强：

- 环形水垢：主环带在模型 z=11.8 cm，叠加厚薄变化、上缘结垢和毛糙边缘；较低位置另有一条旧环带及一条浅痕。
- 整体磨砂与不透明程度：提高矿物薄膜光学厚度和微表面粗糙度。水下仍保留一定乳白浑浊，避免浸水后一下变得完全清透。
- 颗粒污垢：固定在内壁 UV 坐标中，增加不规则细碎附着物，强化下部与局部区域的密度。外壁只保留少量浮尘；不靠全屏噪点制造脏度。
- 反光：复用已有室内 HDRI，加入顶部柔光、侧向反光与相机侧灯板；管件和上盖使用带反射的材质。保留黑色硬件轮廓，并降低传感器噪声，以免把渲染噪点误认成污垢。
